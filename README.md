# Ratnagiri District General Workers Union MIS Portal

Management Information System for रत्नागिरी जिल्हा जनरल कामगार युनियन (संलग्न सीटू).

## Technology

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT with role-based access

## Roles

- **Admin** — manages users, master data, and all records.
- **Operator** — enters and updates application records.
- **Viewer** — has read-only access to dashboards and reports.

## Project folders

- `frontend/` — React website
- `backend/` — API and database access
- `database/` — SQL schema and seed data for applications and master data
- `documentation/` — design, API, and project journal

See [documentation/architecture.md](documentation/architecture.md) for the initial system design.
